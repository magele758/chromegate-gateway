# ChromeGate Gateway 功能地图

这个仓库只做受控浏览器网关。用户入口是扩展弹窗和本机命令 `chromegate-gateway`。每一行是弹窗或命令里真实存在的一项能力。安装扩展和登记 Native Host 的步骤在 [README](../README.md)。没有侧栏对话、剪藏、多站发布、同传或配音。

| 用户入口 | 用户可观察的行为 | 从哪里改 | 从哪里验证 |
| --- | --- | --- | --- |
| 弹窗「启用本机网关」`#gw-enabled` | 勾选且至少有一枚未吊销、未过期的 token 时，扩展连接 Native Host `com.chromegate.gateway`。`#gw-status` 在 `broker.ready` 之后显示「网关已连接」。连接中显示 `connecting`；重连失败显示错误文案；关掉开关或没有有效 token 时显示 `stopped`。未登记 host 时，状态是「未安装 Native Host…」。本仓库不会写入 Chrome 的 NativeMessagingHosts 目录。 | [弹窗](../extension/popup/popup.js)、[开关条件](../extension/lib/bridge/gateway.js)、[连接与重连](../extension/lib/native-port.js)、[host 进程](../native/host.mjs) | [broker、拒绝本机命令](../test/test_gateway.mjs)。勾选后的真机状态要在已加载的扩展弹窗里看 |
| 弹窗「启用 inbox 文件桥（~/.chromegate-gw）」`#inbox-enabled` | 和网关开关一起保存。网关已连接且此项打开时，host 约每 2 秒把 `~/.chromegate-gw/inbox` 里的普通 JSON 转给扩展，结果写到 `~/.chromegate-gw/outbox`，原文件挪到 `inbox/processed`。符号链接和非 JSON 只写出失败结果。未连接或关掉此项时不转发。 | [弹窗](../extension/popup/popup.js)、[把开关交给 host](../extension/lib/bridge/gateway.js)、[轮询](../native/host.mjs)、[搬文件](../native/inbox.mjs) | [入队、转发、outbox 不含 token](../test/test_inbox.mjs) |
| 弹窗「创建」`#tok-create`，名称 `#tok-name`，过期 `#tok-hours` | 名称为空则创建失败。成功后 `#tok-once` 只显示一次明文，前缀是 `cgk_`，并提示保存到 `~/.chromegate-gw/agents/<名称>.token`。扩展只存 SHA-256。`#tok-list` 显示名称、`active` / `revoked` / `expired` 和 scope。小时数换成过期时间；留空则不过期。 | [弹窗](../extension/popup/popup.js)、[创建消息](../extension/sw.js)、[签发与状态](../extension/lib/bridge/auth.js)、[存储](../extension/lib/bridge/token-store.js) | [默认只读、哈希、过期](../test/test_auth_scope.mjs) |
| 新建 token 的 scope `#scopes` | 默认勾选 `tabs:read`（`list_tabs`）和 `page:read`（`query_dom`、`screenshot`、`read_console`、`read_network`）。`tabs:manage`（`navigate`）、`page:act`（`click`、`type`）、`page:js`（`run_js`）默认不勾。未授权的调用返回 `SCOPE_DENIED`，页面不会被改。未知 scope 被丢掉。页面结果带 `untrusted: true`。截图或观察过的标签会出现 Chrome 调试提示条。 | [勾选](../extension/popup/index.html)、[scope 表](../extension/lib/bridge/auth.js)、[工具实现](../extension/lib/bridge/tools.js) | [列表过滤与 SCOPE_DENIED](../test/test_bridge.mjs)、[默认 scope](../test/test_auth_scope.mjs)、[点击与读 DOM](../test/test_page_actions.mjs) |
| 网站白名单 `#tok-origins` | 多行 origin。文本框默认是 `http://127.0.0.1:*` 和 `http://localhost:*`。一个有效 origin 都没有时，创建失败并提示「至少填写一个 origin。」空列表匹配不到任何站。范围外的 `navigate` 返回 `ORIGIN_NOT_ALLOWED`，`list_tabs` 不列出范围外的标签。亲手输入 `*` 会匹配任意 http/https。 | [文本框](../extension/popup/index.html)、[创建前校验](../extension/sw.js)、[模式匹配](../extension/lib/bridge/policy.js)、[token origin](../extension/lib/bridge/auth.js) | [范围外导航被拒绝](../test/test_bridge.mjs) |
| Token 列表 `#tok-list` 的「吊销」 | 只有 `active` 的 token 显示这个按钮。点一次后状态变为 `revoked`，按钮消失。之后再用这枚明文调用，返回 `UNAUTHORIZED`。过期同样拒绝，弹窗里没有单独的「设为过期」按钮。 | [按钮](../extension/popup/popup.js)、[吊销消息](../extension/sw.js)、[写入 revokedAt](../extension/lib/bridge/token-store.js) | [吊销后校验失败](../test/test_auth_scope.mjs) |
| 待确认 `#approvals` 的「允许」「拒绝」 | 点击可见文案像发布、发送、提交或删除，或者导航到结账 URL，调用返回 `CONFIRMATION_REQUIRED`，弹窗列出原因。允许只放行这一次完全相同的参数；再调用一次会重新排队。拒绝返回 `CONFIRMATION_REJECTED`。队列为空时显示「无」。scope 不够的调用在进入队列之前就被拒绝。 | [按钮](../extension/popup/popup.js)、[队列消息](../extension/sw.js)、[一次消费](../extension/lib/trust/approval-queue.js)、[命中规则](../extension/lib/trust/irreversible.js)、[拦截](../extension/lib/bridge/trust-guard.js) | [批准只消费一次、结账导航](../test/test_bridge.mjs) |
| 审计 `#audit` | 打开弹窗时列出最近 30 条。每条是 `ok` 或错误码、agent 名、工具名。弹窗没有清空按钮。写入审计的参数摘要会打码 token。 | [列表](../extension/popup/popup.js)、[读取最近记录](../extension/lib/bridge/gateway.js)、[记录格式](../extension/lib/bridge/audit.js) | [参数摘要打码](../test/test_auth_scope.mjs)。最近 30 条的弹窗显示要在已加载的扩展里看 |
| 「允许用户脚本（run_js 的 CSP 后备）」`#allow-userscripts` | 点击后 Chrome 询问可选权限 `userScripts`。`run_js` 先走调试器 `Runtime.evaluate`；只有 CSP 挡住时才走用户脚本。不授予这项权限时，没有挡住 `Runtime.evaluate` 的页面仍然可以执行。 | [按钮](../extension/popup/popup.js)、[两条执行路径](../extension/lib/run-js.js) | [调试器优先、用户脚本回退](../test/test_auth_scope.mjs) |
| `chromegate-gateway verify scenario.json` | `--dry-run` 只打印将调用的工具和断言，不连网关。正式跑需要 `--token-file` 或环境变量 `CHROMEGATE_GW_TOKEN`。`--var key=value` 替换场景里的 `{{key}}`。步骤只能是 `list_tabs`、`navigate`、`click`、`type`、`screenshot`、`query_dom`、`run_js`。断言失败就停，输出里 `healed` 为 false，并在 `--outbox` 或 `~/.chromegate-gw/outbox` 写 markdown；采到截图时再写 jpeg。后面的步骤不跑。模板是 [identity](../scenarios/identity.json)、[stream-integrity](../scenarios/stream-integrity.json)、[dialog-state](../scenarios/dialog-state.json)。 | [命令](../native/cli.mjs)、[回放与证据包](../native/verify.mjs) | [断言、失败即停、dry-run](../test/test_verify.mjs) |
| `chromegate-gateway inbox enqueue` 与 `chromegate-gateway inbox status` | `enqueue --tool <名> --token-file <文件> [--arg key=value]` 只在 `~/.chromegate-gw/inbox` 写一份 JSON，并打印 job 路径和对应的 outbox 路径。`status` 打印两边的 JSON 文件数。outbox 不回写 token。`CHROMEGATE_GW_HOME` 可改根目录。文件要被 host 转发，还需要弹窗里的 inbox 开关，以及已经连上的网关。 | [命令](../native/cli.mjs)、[入队与写出](../native/inbox.mjs) | [入队、处理、outbox 不含明文 token](../test/test_inbox.mjs) |
| `chromegate-gateway mcp-config` | 向 stdout 打印 Cursor、Claude Code、Codex 三段配置。stderr 说明这条命令不写编辑器配置，也不登记 Native Host。 | [打印片段](../native/cli.mjs) | [片段字段](../test/test_gateway.mjs) |
| `node native/host.mjs --mcp --token-file <文件>` | 这是 `mcp-config` 片段里启动的进程。没有 token 时进程以状态 1 退出，不退回 shell。连上 `~/.chromegate-gw/bridge.sock` 后，MCP `tools/list` 返回扩展按 scope 给出的工具，并隐藏 `list_tools`。`--agent-name` 改审计里的名字，默认是 `mcp`。host 拒绝 `exec`、`fs`、`shell`、`clipboard_write`。 | [MCP 启动](../native/host.mjs)、[工具转发](../native/mcp.mjs)、[socket](../native/gateway.mjs) | [隐藏 list_tools、拒绝未知工具和本机命令、配置片段](../test/test_gateway.mjs)。退出码 1 的启动分支没有单独测试 |
